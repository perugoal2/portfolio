First-time setup
  1. On GitHub, create a new private repo named hunter-data.
  2. Upload codex.md to it (or paste it into the Codex section after unlocking).
  3. Settings → Developer settings → Fine-grained tokens → Generate. Repository access: only hunter-data (add portfolio too if you want to publish a public view). Permissions: Contents, read and write. Choose an expiry.
  4. Paste the token above. It's kept in this browser only. Press Lock on shared computers.
